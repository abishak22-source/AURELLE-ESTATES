# Aurelle Estates — Luxury Real Estate Landing Page

A premium editorial-style real estate landing page built with separate HTML, CSS and vanilla JavaScript files.

## Run locally
1. Extract the ZIP.
2. Open the `aurelle-estates` folder in VS Code.
3. Open `index.html`.
4. Right-click and choose **Open with Live Server** (if Live Server is installed).

## Files
- `index.html` — semantic page structure and section comments.
- `css/style.css` — design system, layouts, responsive rules and CSS comments.
- `js/script.js` — sample property data, filtering, mobile navigation, scroll reveal and form validation.

## Notes
- Property listings and prices are fictional demo content.
- Images and Google Fonts load from external services, so internet access is required.
- The enquiry form is frontend-only. It validates input but does not send or store submissions.
- Replace demo images, contact details, property data and prices before using this as a real business website.
